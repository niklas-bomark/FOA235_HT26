10  Cluster Analysis: Lab 2

Multidimensional Cluster Analysis

In this lab, we will import a dataset containing many variables, standardize the variables, and then perform a k-means cluster analysis to explore whether there are distinct groups in the data. Since we are working with multidimensional data, we will use Principal Component Analysis (PCA) to visualize the resulting clusters in two dimensions. We will also evaluate the clustering solution using the elbow method. Finally, we will interpret the results and make a decision about whether the chosen clustering model should be implemented in the company.

We will follow this basic workflow when we work with K-Means Cluster Analysis:

  1. Explore the data.
  2. Select the variables to include in the cluster analysis.
  3. Standardize the variables so that differences in scale do not influence the clustering.
  4. Choose the number of clusters, \(k\).
  5. Run the K-means algorithm.
  6. Inspect, interpret, and visualize the resulting clusters. If the data contain more than two variables, we can use PCA to represent the clusters in two dimensions.

10.1.2.6 How many clusters should we use?

K-means requires us to choose the number of clusters, (k), before estimating the model. One common method for selecting (k) is the elbow method. The elbow method compares the total within-cluster variation for different values of (k).

set.seed(123)

fviz_nbclust(
  df_scaled,
  kmeans,
  method = "wss",
  k.max = 10
)

The vertical axis shows the within-cluster sum of squares. As the number of clusters increases, the within-cluster variation decreases. However, adding more and more clusters eventually produces only small improvements. We look for an elbow in the plot: a point where adding another cluster produces a much smaller improvement.

Questions:
- Where do you see an elbow in the figure?
- How many clusters would you choose?
- Is the choice completely obvious?

10.1.2.11 Why can we not simply plot all variables?

If we only had two variables, we could plot one on the x-axis and one on the y-axis. However, our cluster analysis contains several variables. This means that the observations exist in a multidimensional space. To visualize the clusters, we use Principal Component Analysis (PCA). PCA summarizes the variation in many variables using a smaller number of dimensions (in our case: 2!). We will not focus on how to perform PCA or on the mathematical details behind it. However, you should understand the basic idea and purpose of PCA, as this will help you interpret the visualizations we create.

10.1.2.12 Visualize the clusters using PCA

We will use the factoextra package, which allows us to apply PCA and visualize our clusters in two dimensions. This is particularly useful when our cluster analysis includes more than two variables and the data therefore cannot be visualized directly in a simple scatterplot.

fviz_cluster(
  km,
  data = df_scaled,
  geom = "point",
  ellipse.type = "convex",
  ggtheme = theme_minimal()
)

10.1.2.13 Compare alternative models

Suppose you are considering models with 2, 3, and 4 clusters. Run all three models.

set.seed(123)

km2 <- kmeans(
  df_scaled,
  centers = 2,
  nstart = 25
)

km3 <- kmeans(
  df_scaled,
  centers = 3,
  nstart = 25
)

km4 <- kmeans(
  df_scaled,
  centers = 4,
  nstart = 25
)

Calculate their average silhouette coefficients.

comparison <- data.frame(
  clusters = c(2, 3, 4),
  WSS = c(
    km2$tot.withinss,
    km3$tot.withinss,
    km4$tot.withinss
  )
)

comparison
  clusters       WSS
1        2 1457.3222
2        3  804.8805
3        4  722.2749

However, WSS will decrease as we add more clusters. Therefore, we should not simply choose the model with the lowest WSS. Instead, consider how much WSS decreases when moving from 2 to 3 clusters and from 3 to 4 clusters. This is the same logic that underlies the elbow method. We can calculate the change in WSS explicitly:

comparison <- comparison |>
  mutate(
    WSS_reduction = lag(WSS) - WSS
  )

comparison
  clusters       WSS WSS_reduction
1        2 1457.3222            NA
2        3  804.8805     652.44173
3        4  722.2749      82.60554

Questions: - How much does WSS decrease when moving from 2 to 3 clusters? - How much does it decrease when moving from 3 to 4 clusters? - Which model is easiest to interpret?
