5.1 Editing Data

In this chapter, we will introduce a few common ways to edit and transform data in R. You can return to this chapter later in the course whenever you need to modify, clean, or restructure your data.

We will begin by adding code to clear the R environment. Clearing the environment removes objects that were created during previous work and gives us a clean starting point. After clearing the environment, you need to load the packages you want to use again with library(). This helps ensure that objects left over from previous analyses do not accidentally interfere with your current work.

We will then import a dataset that we will use throughout the chapter to practice different ways of working with and modifying data.

Open the Lab2.qmd file located in the Lab_files folder. As you work through this chapter in the course compendium, copy the code examples into your Quarto document and run them yourself. Try to understand what each line of code does, what changes it makes to the data, and why we might want to make that change. You will use many of these techniques again later in the course.

5.1.1 Variable names

Sometimes we need to rename variables. To rename variables, you can use the following principles:

  • df indicates the object we want to edit.

  • |> is called a pipe and tells R to continue by adding more operations to the object (in this case, df). You need to have the package dplyr installed and loaded.

  • The function rename() helps us rename variables. The first argument in rename() is the new name, and the text inside "" after = is the old name.

  • The function head() tells R that after renaming the variables, we want to display the first six rows of our data frame.

Here is the code:

# Edit and save the new variable names in a new dataset (object) called df_clean
df_clean <- df |> 
  rename(
    age        = "Age..years.", 
    income     = "Income.kr",      
    group      = "Group",          
    codex      = "CodeX",         
    measurement = "Measurement"    
  )

After running the code, you should see a new object in R — df_clean — and if you click on it, you’ll see the new dataset with the updated variable names. You can also use the function summary() to take a look at the new dataset:

5.1.3 Mutate

The mutate() function from dplyr is used to modify existing variables or to create new variables in a data frame.

Mutate() can be used to modify an existing variable. For example:

df_clean <- df_clean |>
  mutate(
    price = price * 1.10
  )

Here, the existing price variable is replaced with a new version in which all prices have been increased by 10%.

Suppose our dataset contains the variables price and quantity. We can create a new variable called revenue:

df_clean <- df_clean |>
  mutate(
    revenue = price * quantity
  )

The original variables remain in the data frame, and revenue is added as a new variable. We can also create several variables at the same time:

df_clean <- df_clean |>
  mutate(
    revenue = price * quantity,
    revenue_thousands = revenue / 1000
  )

During the course, we will use mutate() when we need to create or transform variables before performing an analysis.

5.1.4 Group

Sometimes we want to calculate statistics for different groups of observations rather than for the entire dataset. For this, we can combine group_by() and summarise() from dplyr.

Suppose our dataset contains a variable called region. We can group the observations by region. By itself, group_by() does not calculate anything. Instead, it tells R that subsequent operations should be performed separately for each group. We can then use summarise() to calculate summary statistics for each group:

df_clean |>
  group_by(region) |>
  summarise(
    mean_revenues = mean(revenue)
  )
# A tibble: 4 × 2
  region mean_revenues
  <chr>          <dbl>
1 East           3622.
2 North          3072.
3 South          3206.
4 West           3117.

This code can be read as: Take df, then group the observations by region, then calculate the mean of sales separately for each region. We can calculate several statistics at the same time:

df_clean |>
  group_by(region) |>
  summarise(
    n = n(),
    mean_sales = mean(revenue),
    min_sales = min(revenue),
    max_sales = max(revenue)
  )
# A tibble: 4 × 5
  region     n mean_sales min_sales max_sales
  <chr>  <int>      <dbl>     <dbl>     <dbl>
1 East      68      3622.     235.      9600.
2 North     61      3072.     162.      9256.
3 South     87      3206.      77.4    10033.
4 West      84      3117.      66.5     9434.

Here: - n() counts the number of observations in each group. - mean() calculates the mean. - min() identifies the minimum value. - max() identifies the maximum value.

The combination of group_by() and summarise() is particularly useful when we want to compare different groups in our data. Note that we don’t ‘save’ the summary statistics we just calculated to a new object

5.1.5 Factors

You always need to be aware of the type of data you are working with. Different data types may need to be handled differently in R. For example, we often need to convert categorical variables into factors. We can do this using the functions mutate() and as.factor().

A factor variable represents data that consist of a set of distinct categories. These categories do not necessarily have a natural order. For example, consider a variable describing the region in which a customer lives:

  • North
  • South
  • West

There is no meaningful ranking among these categories. North is not higher or lower than South or West. This is an example of a nominal categorical variable. In R, we can represent such a variable as an unordered factor.

# Mutate
df_clean <- df_clean |>
  mutate(
    region = factor(
      region,
      levels = c("North", "South", "West"),
      ordered = FALSE
    )
  )

Sometimes, we want to specify an order for the categories of a factor variable. We can do this by setting ordered = TRUE.

5.1.6 Filter

Sometimes we want to edit the rows in our data table. For example, there may be some values that are clearly miscoded. Let’s handle them using a filter with the filter() function. We create a condition — we want to keep only the values that are equal to or greater than 0. Values that are below 0 will simply be removed.

# Filter
df_clean <- df_clean |> 
  filter(price >= 60)     # keep only price values that are 60 or higher

Let’s add a filter that removes all negative values, and another that removes obviously miscoded large values. We use the pipe: |>

This time, we will also save the filtered data to the object ‘df_clean’:

df_clean <- df_clean |> 
  filter(price >= 60) |>        # keep only values that are 60 or higher
  filter(price < 9999999)       # remove extremely large values

We can use filter() when we want to select observations based on their values.

5.1.7 Create new categorical and binary variables

We can also create factors from continuous variables using the functions mutate() and cut(). For example, we can divide the age variable into two groups: younger and older. First, we create the categories and then take a look at the result:

# Example: create categories from a continuous variable
df_clean <- df_clean |>
  mutate(
    age_cat = cut(age,
                  breaks = c(0, 50, Inf),
                  labels = c("Young", "Older"))
  )

We can also create a new variable with two age categories by using a binary numerical indicator variable:

# Example: create a binary numerical variable from a continuous variable
df_clean <- df_clean |>
  mutate(age_binary = ifelse(age > 50, 1, 0))
